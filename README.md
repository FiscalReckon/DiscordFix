> ### АНТИВИРУСЫ
> Антивирус может среагировать на WinDivert.  
> WinDivert перехватывает и фильтрует трафик, поэтому нужен для работы zapret.
> Один и тот же инструмент могут применять и безопасные, и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует файлы WinDivert как инструменты повышенного риска или хакерские утилиты. В результате файл удаляется и отправляется в карантин. Название детекта обязательно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть настройка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". При точной настройке исключений предпочтительно добавить исключение, но если вы не полностью понимаете последствия, рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome активируйте "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщик по умолчанию"
    * В Firefox включите "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query` (поставщик Cloudflare может быть заблокирован)
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы - [инструкция доступна здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, настройка и работа Secure DNS на компьютере могут нарушиться

2. Загрузите zip- или rar-архив со [страницы последнего релиза](https://github.com/FiscalReckon/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и установите флажок "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно не выполнять

4. Распакуйте архив в путь, где нет кириллицы и специальных символов

5. Запустите необходимый файл
    * Чтобы найти рабочую стратегию: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для установки автозапуска: **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вас**

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавить любую стратегию в автозапуск через services.msc</ins>
  - **`Remove Services`** - убрать стратегию и WinDivert из служб
  - **`Check Status`** - посмотреть состояние обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** - изменить режим обхода для игр и других сервисов, использующих UDP и TCP на портах выше 1023.  
  **После изменения необходимо перезапустить стратегию.**  
  Текущее состояние показывается в скобках: включено или выключено.
  - **`IPSet Filter`** - выбрать режим обхода для сервисов из `ipset-all.txt`.  
  Этот параметр полезен при проверке ресурса, который без zapret работает, а с ним нет.  
  В скобках отображается текущий режим:
    - `none` - ни один IP не проходит проверку
    - `loaded` - IP проверяются на наличие в списке
    - `any` - под фильтр попадает любой IP
  - **`Auto-Update Check`** - включить или отключить автоматическую проверку обновлений
  - **`Replace active fakes`** - заменить текущий фейк другим файлом из каталога `bin`
  - **`Update IPSet List`** - загрузить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовым чатам Discord**</ins>
  - **`Check for Updates`** - вручную проверить наличие обновлений
  - **`Run Diagnostics`** - проверить распространённые причины неработоспособности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает, если приложение внезапно перестало работать
  - **`Run Tests`** - открыть инструмент проверки стратегий:
    - `Standard tests` - тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` - проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe (обход), видимый на панели задач.  
Если этого не случилось, ознакомьтесь с [#522](https://github.com/FiscalReckon/zapret-discord-youtube/issues/522)

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не работает Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если файл hosts окажется устаревшим, программа предложит обновить его вручную:  
  - Выделите и скопируйте весь текст из открытого блокнота
  - В открывшейся папке найдите `hosts` и откройте его текстовым редактором от имени администратора
  - Вставьте скопированное в конец `hosts` (либо замените ранее добавленные аналогичные строки)
  - Сохраните файл и проверьте подключение ещё раз. Если результата нет, убедитесь, что сохранение действительно прошло.

#### Работа не гарантируется. При отсутствии результата используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/FiscalReckon/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем перестать работать.**
> Некоторая стратегия может действовать какое-то время, а затем перестать работать после обнаружения её параметров.
> В репозитории есть множество стратегий обхода. Если готовые варианты не помогают, создайте новую на основе одной из них, изменив параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте наличие ошибок через `service.bat` -> `Run Diagnostics`

- Убедитесь, что нужный адрес присутствует в списках доменов или IP

- По очереди проверьте другие стратегии, в том числе **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация есть в [#765](https://github.com/FiscalReckon/zapret-discord-youtube/issues/765)

### Как полностью переустановить или обновить?
- Сохраните добавленные вами ресурсы и данные
- Перезапустите устройство
- Выполните `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; при наличии ошибок исправьте их, затем в конце выберите Y
- Удалите старый каталог zapret
- Скачайте свежую версию [со страницы релизов](https://github.com/FiscalReckon/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву и откройте свойства. Если внизу справа есть пункт разблокировки, установите его, нажмите применить и ОК
- Распакуйте архив в новую папку в корне диска, без пробелов и специальных символов
- Запускайте разные `general`-скрипты и проверяйте доступность ресурсов. Если интернет-ресурсы не открываются, закройте программу через значок замка на панели задач и попробуйте следующую стратегию
- После выбора рабочей стратегии установите её в автозапуск: `service.bat` -> `Install Service` -> выберите нужный вариант

### Не работает игра или приложение при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о WinDivert

- Инструкция находится здесь: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. Определите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал бороться с ними.
- Переберите остальные стратегии, особенно если раньше всё работало.
- См. также [#251](https://github.com/FiscalReckon/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что настроен [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её
- В `service.bat` выберите `Run Diagnostics`, затем очистите кэш Discord
- Проверьте приложение Discord после очистки кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей
- Если браузерная версия тоже недоступна, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/FiscalReckon/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/FiscalReckon/tg-ws-proxy)
- Также можно использовать бесплатные MTProto-прокси из интернета

### Не работают игры

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Универсальная последовательность действий:
- через `service.bat` обновите ipset и активируйте `Game Filter`
- если это не помогло, дополнительно включите `ipset any`

Учитывайте, что `ipset any` может нарушить открытие множества сайтов. Не оставляйте этот режим включённым постоянно: определите IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/FiscalReckon/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Проблема не описана

- Сообщите о ней [здесь](https://github.com/FiscalReckon/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода можно указать в следующих файлах:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** - домены-исключения, например когда IP сети есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, которые нужно исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
